# Gestapelte Hidden-Markow-Modelle

## Installation

In deiner Python (3.12) venv:

    $ python -m pip install numpy
    $ python -m pip install tensorflow[and-cuda]
    $ python -m pip install hidten
    $ python -m pip install matplotlib

Optional:

    $ python -m pip install git+https://github.com/IbuCrackt/ibutils.git@v0.0.1

## Klassifizierungstask

    $ python run_classification.py

## Token-Level-Task

    $ python run_token_level.py

Beide Task erstellen Ordner mit ihren geplotteten Ergebnissen.
